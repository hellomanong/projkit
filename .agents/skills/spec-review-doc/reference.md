# 章节规则与模板铁律

## 一、章节规则（内容怎么拼）

评审稿的读者是**没参与访谈的人**——每节都要经得起「零上下文能不能看懂」检验；排版守项目 `docs/PROJECT-GUIDE.md`「文档排版规范」，概念第一次出现给一句人话解释。

| 板块 | 取材 | 规则 |
|---|---|---|
| 文件头（tblock） | — | 项目名、标题、一句话说明、元信息栏（范围/版本/日期/成熟度/取材）、印章、评审人会签栏（不需要就删） |
| 评审综述（changes） | 全部产物 | TL;DR：3–5 句说清这范围要做什么、进展到哪、本稿请评审什么；三张卡分「已拍板 / 进行中 / 请评审」 |
| 需求解读 | `解读/<范围>.md` | 按块搬运并压缩；图忠实转译成内联 SVG（§二）；模糊点已有解答的并入正文，没解答的归「未决问题」 |
| 当前有效决策 | 该范围全部 ADR | **新盖旧合并成终态清单**：被修订的只显终态、尾注「经 NNNN 修订」；每条按 ADR 的「问题 / 方案」结构呈现（有代价行的一并带上）；每条尾注来源 ADR 编号 |
| 设计方案 | `ARCHITECTURE.md` / `specs/<范围>.md` / 解读 | 有才有此节；结论摘要 + 架构图——SPEC 的模块图（本轮视角）**忠实转译成 SVG**（节点/连线/文字一一对应，不增删），模块范围稿另**现画模块稳态架构图**（规范见下）；节标题挂成熟度徽标 |
| 未决问题与评审请求 | ADR「未决问题」节 + 解读模糊点 | 每条写明「请评审人回答什么」；提不出具体问题的未决项标「暂无具体问题，欢迎意见」 |
| 明确不做 | ADR / 解读 | 框定边界，防评审人对着范围外提意见 |

**模块稳态架构图**（模块范围稿的「设计方案」节内现画，内联 SVG——排版规范见 §二）：

- **详细程度对标全局架构图**，不是三五个框的示意图：分层展开——对外接口 → 内部子组件 → 数据/存储 → 外部依赖，边上标数据流向、节点到子组件粒度；不标新建/改造（稳态视角没有「本轮」）。
- **主要取材该模块解读**（需求细节最全的地方）——解读里的每条主要流程都要能在图上走通；SPEC 的文件与接口、ADR 决策补结构细节。
- 只许投影产物已有信息（口径见 SKILL.md 红线）；**衍生视图**——图的正本永远是产物文件，不回写三环产物，版本间图有出入以产物为准。

**成熟度**（文件头元信息栏与设计方案节标题用）：

- 「SPEC 已定稿」——`specs/<范围>.md` 存在（全局范围看 `ARCHITECTURE.md` 存在）
- 「设计草稿」——只有 `.draft.md`
- 「仅访谈」——只有解读 + ADR

模块范围稿**不带全局背景章节**（文档小、针对性强是拍板取舍）；文件头标注所属项目即可。空章节（如无设计方案）整节删除，侧边导航对应项一并删——不留空节。

## 二、模板使用铁律

- `template.html` 从本 skill 目录**原样拷贝**，只替换 `<!-- FILL:名字 -->` 与 `<!-- /FILL:名字 -->` 之间的内容区（部分 FILL 区的示例骨架写在注释里，照抄结构再填内容）；模板**既有** CSS、页面骨架、脚本一个字符不动（图专属 style/script 属 FILL 内容区，允许新增，见下条）。
- 正文章节一律 `<section class="sec" id="sN">`，标题 `<h2><span class="no">§ 0N</span>标题</h2>`，导读用 `<p class="lede">`；小节标题 `<h3><span class="h3no">N.M</span>标题</h3>`。
- 侧边导航（`FILL:side-nav`）与正文章节一一对应：删了哪节，导航里同步删。
- 架构图一律**内联 SVG**，画法照 **`diagram.md` 范式**（结构五件套、排版算法、配色引模板变量、交互按规模两档自适应、骨架样例）——自包含、离线可看，零外部依赖（Mermaid/CDN 已退役）。图专属的 `<style>`/`<script>` 允许写在内容区，但选择器与脚本必须以本图 `id` 限定作用域，不得波及模板既有样式与骨架。产物里的 Mermaid 图转译成 SVG 时结构忠实：节点、连线、文字一一对应，不增删。
- 成熟度徽标：`<span class="b b-k">SPEC 已定稿</span>`、`<span class="b b-r">设计草稿</span>`、`<span class="b b-g">仅访谈</span>`。
- 决策清单用 `.prin` 编号条目（`pno` 写 D1、D2…）：`h4` 放问题（来源尾注 `<span class="src">ADR 0003</span>` 挂标题尾），正文 `p` 放方案，代价（如有）跟在方案后。
- 未决问题用 `<div class="callout amber"><b>请评审 · Q1</b>问题与期望的回答。</div>`；警示/背景说明可用 `.callout.warn` / `.callout.blue`。
- 表格包 `<div class="twrap">`；模块/概念卡片可用 `.defs`；步骤时序可用 `.timeline`。
- 版本自增规则：`ls docs/review/<范围>-v*.html` 取最大版本，末段 +1（v0.5 → v0.6，v0.9 → v0.10）；大版本跳变由用户手动指定，不自动进位。
